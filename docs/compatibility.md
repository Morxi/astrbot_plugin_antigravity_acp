# 兼容补丁登记与退役条件

> 基线：**v0.8.0**（AstrBot `>=4.29.4,<4.30`，Python 3.11+）。此表是对当前源码的维护导航，不是把所有兼容逻辑都当作临时补丁。**识别 4.30 的部分文案不代表兼容 4.30 runner/API**。修改前先固定宿主、CLI、模型、重现路径与基线 SHA，参考 [测试与交付](testing.md)。

## 宿主/上游定点兼容

| 编号/位置 | 具体边界 | 保留理由 | 退役或调整的证据门槛 |
| --- | --- | --- | --- |
| #14 `system_prompt.py::filter_host_capabilities` | 仅过滤已知 AstrBot 4.29.4/4.30 的失实“本地电脑能力”独立行或可验证完整块；未知结构保留 | 宿主声明本机执行能力，但 Provider 有意不开放内置 shell/file/browser；原报告曾独立复现内容相关 429 | 宿主真实提供可协商的能力合同，或目标版本不再注入该声明；与原宿主 system 做字节级差异回归，再按宿主版本逐步删除 |
| #19 `system_prompt.py::_rewrite_safe_mode_rules` | 仅匹配完整 Safe Mode 规则列表内的第 4 条，将 `style/role-play` 等义改成 `style and role-play`，保留规则与语义 | 4.29.4 真实样本出现无明细 429，定点改写在记录的实机链路恢复 | 上游规则文本/服务策略稳定修复；以新旧真实模板和合成规则测试证明无误删、无回归，再撤销 |
| 4.29.4 `host_compat.py` | 仅拦截本 Provider 已输出/已交接后失败的 fallback/retry 路径，不改变其他 Provider | 宿主 runner 异常处理可能重复生成，甚至重复有副作用工具 | 目标 AstrBot 版本原生保证不重放；需用该版本源码与真实流式/工具中断路径验证后再移除包装 |
| #7 `notices.py` / `errors.py` | 对 CLI 的跨分片重试提示做有界识别，避免把容量告警当正文并做保守分类 | 上游错误不总有稳定结构化字段；用户曾遇到 `API error (attempt N)` 进入回答 | CLI/ACP 提供可靠的结构化错误，且真实告警/部分正文场景全部通过回归；不能仅凭单条日志删除 |
| Windows #8/#9/#22 `paths.py` / `process.py` / `windows_job.py` | 长路径、进程树清理与 Python 3.12+ 关闭顺序兼容 | 平台和运行时差异客观存在 | 分平台证明旧路径不再需要；不能从 Ubuntu 绿灯推断 Windows 不需要 |

## 协议适配及安全不变量（不可按“临时补丁”直接删除）

| 位置 | 必须维持的契约 |
| --- | --- |
| #12 `transport.py` / `tool_turn.py` | 只允许当前活跃 prompt 中已观测、匹配的 MCP 调用获得一次性许可；宿主审批、工具身份、预算和结果回填继续生效。内置终端/文件/web/browser 请求依然拒绝 |
| #13 `tools.py` | Gemini wire schema 和宿主原始 schema 分离，模型侧补充兼容字段不应收窄宿主可接受参数；原始参数继续由宿主执行前校验 |
| #24 `messages.py` / `media.py` | 历史图仅作哈希占位、当前轮图片才当 ACP 附件；这属于历史重放正确性，不是可以随宿主升级直接删除的兼容层 |
| `failure_guard.py` / `telemetry.py` | 限流/配额冷却与候选 429 遥测是本地防雪崩和观测机制；`content_429_candidate` **不证明**上游 429 的根因 |
| `media.py` | 图片 CRC、大小、目录和 SSRF 校验是输入安全边界，不能为了兼容截图或解决预检而绕开 |

## 仍需关注的验证边界

- **历史图片预检未解决**：v0.7.4 的 `prompt_blocks()` 阻止旧图作为当前附件发送，但 `prepare_media()` 仍从历史 contexts 读取、验证并统计旧图，可能导致本轮过早报 `IMAGE*` 或预算超限。解决时必须重构规范化、会话复用哈希/原始内容一致性与媒体预算的约束，补齐“旧图文件删除 / URL 失效 / 总数超限 / 变更图片内容 / 工具续轮”的回归，不能简单跳过历史消息而损坏复用指纹。
- **4.30 宿主尚未完成兼容验收**，macOS、长期认证刷新、生产高并发、QQ 工具链也不能用离线模拟替代。
- 新版可能让旧补丁不再触发；应先用诊断或测试记录命中率与真实模板，再逐项退役，不要一次性全删。

当前故障索引见 [架构导航](architecture.md#故障定位索引)，具体排障见 [troubleshooting.md](troubleshooting.md)。
